# APL/S tapes

Trimmed recordings of 16 James Price APL/S programs entered from the VBK listings.

Load the APL/S cartridge with Expander 1 firmware available. Choose **Mount Playback Tape**, select a `.vbt`, then enter `LOAD` and press NEXT (F3/Enter). Wait for `TAPE OK`, then type the command in the filename's brackets and press NEXT. Use **Rewind Playback Tape** before loading the same tape again.

These images have no spare recording capacity. Use a separate [blank tape](../blank-tape.vbt) for SAVE.

Tapes for Sine Graph, Fibonacci, Random Bars, Pyramid, Recursive Factorial, Acey Ducey, and Dicejack are still pending. [VBK files and source listings](../21-apl_s-games-james-price) are available.
